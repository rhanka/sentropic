# Fix: brace-expansion advisory drift blocking main (Jul 25 2026)

## Objective
Unblock CI on `main` and every open PR. Advisory GHSA-mh99-v99m-4gvg (HIGH) was published
2026-07-23 against `brace-expansion <=5.0.7` — a range far wider than the previous drift fixed
in #445. It supersedes the scoped `brace-expansion@<1.1.16` / `@>=2.0.0 <2.1.2` overrides, whose
pinned versions (1.1.16, 2.1.2) are themselves inside the new affected range with no backport
published. The gate `npm audit --audit-level=high --omit=dev` therefore fails on `main` itself
(`build-api-image`, `build-ui`, `typecheck-lint-api`, `typecheck-lint-ui`), which skips
`publish-api-image` / `publish-ui-image` and breaks `deploy-preprod`.

The only patched release is `brace-expansion@5.0.8`, whose CommonJS build exposes a named
`exports.expand` instead of `module.exports = expandTop`. It is therefore NOT drop-in for
`minimatch@3.x/5.x`, which consume it as a callable. The whole chain must move together:
`brace-expansion@^5.0.8` + `minimatch@^10.2.5` (first line outside the vulnerable
`2.0.0 - 10.0.2` range, and written against the 5.x API) + `glob@^11.1.0` (outside the vulnerable
`4.3.0 - 10.5.0` range, and the version `minimatch@10` targets).

Chain moved: `exceljs → archiver → {archiver-utils, readdir-glob, zip-stream} → glob → minimatch
→ brace-expansion`, plus `rimraf`. Because the consumers pinned to the old `glob` callback API are
transitive and not exercised by `exceljs` (which streams buffers and never calls `archiver.glob()`),
the move is validated empirically rather than assumed — see `## Runtime validation`.

Note: the `glob: ^11.1.0` override already present in `api/package.json` was inert — npm honours
`overrides` only in the workspace-root manifest. This branch moves it to the root, where it applies.

## Scope / Guardrails
- Dependency-only change: root `package.json` `overrides` + regenerated `package-lock.json`.
- No source, no Makefile, no docker-compose change.
- Lockfile regenerated by deleting `package-lock.json` first, because `npm install --package-lock-only`
  on a complete lockfile does not re-apply newly added overrides.
- Make-only workflow. All new text in English.

## Advisory fixed (HIGH only — the gate is `--audit-level=high`)
- `brace-expansion` — DoS via unbounded expansion length (OOM crash) — GHSA-mh99-v99m-4gvg —
  affected `<=5.0.7`, patched `5.0.8`. 9 of the 11 reported vulnerabilities were this single root
  cause reported through its dependents (`minimatch`, `glob`, `archiver-utils`, `archiver`,
  `readdir-glob`, `zip-stream`, `rimraf`, `exceljs`).
- Superseded and removed: `brace-expansion@<1.1.16` → `1.1.16` and `brace-expansion@>=2.0.0 <2.1.2`
  → `2.1.2` (both now inside the affected range).
- Out of scope: the remaining `@hono/node-server` / `@modelcontextprotocol/sdk` / `file-type` /
  `@jimp/core` advisories are `moderate` and do not trip the `--audit-level=high` gate.
