# Image Generation Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `image_generate` as a first-class chat tool backed by `@sentropic/llm-mesh.generateImage()`, with OpenAI `gpt-image-2` and Gemini `gemini-3.1-flash-image-preview` support.

**Architecture:** Add a separate mesh image operation, bridge it through API provider runtimes, store generated images as local `context_documents`, and render generated media cards in chat. Generated bytes stay in storage, never in chat message text.

**Tech Stack:** TypeScript, Vitest, Svelte 5, Hono, Drizzle, S3-compatible document storage, `@sentropic/llm-mesh`, OpenAI Images API, Gemini `generateContent`.

---

## File Structure

- `packages/llm-mesh/src/image-generation.ts` plus `{capabilities,providers,catalog,adapter-core,registry,mesh,index}.ts`: image types, capabilities, catalog, adapter/facade operation.
- `api/src/services/{provider-runtime,providers/openai-provider,providers/gemini-provider,llm-runtime/mesh-dispatch,llm-runtime/index,document-generated-media,tools,chat-service}.ts`: runtime bridge, storage, tool definition, execution.
- `packages/chat-ui/src/{client/streamTypes,components/StreamMessage}.ts`, `ui/src/lib/chat/document-adapter.ts`, `ui/src/lib/components/chat/AppChatPanel.svelte`: generated image extraction and rendering.
- `spec/*.md`, package `package.json`, `BRANCH.md`: docs and publish gates.
