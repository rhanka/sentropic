## Authority and ownership

`AdmissionAuthority` obtains tenant, workspace and actor from a request/session-bound host authentication port, compares caller actor identity/kind, checks document/field/operation grants, and reauthorizes operations against both persisted admission bounds and current grants. Actor presentation comes from the host. A document admission rejects an actor ID already recorded under another kind, before schema recovery or storage mutation; the identity issuer owns global ID uniqueness. The atomic storage callback serializes per tenant/workspace/document/actor key. Its record contains session ID, profile/schema facts and admission epoch. Reconnect/recreated services retain the epoch; only explicit close/new admission rotates it. Admission bounds remain fixed upper bounds: newly widened grants require close/new admission. Narrowed grants take effect on the next check.

`LiveSessionProvider` joins admission, preserved-draft recovery and binding allocation. Mismatch refuses before registry allocation, captures the offline draft and returns its capture ID in the refusal. Recovery state is keyed by tenant/workspace/document/actor/draft, with a pending pointer so changing handshake facts or restarting cannot bypass acknowledgement. Capture IDs identify immutable bytes and source facts: changed bytes require a new ID; conflicting reuse refuses `draft-id-reuse`, preserving the original. Distinct captures remain addressable and the latest pending capture drives recovery. Client upgrade retains bytes; draft migration receives only a copy and schema facts. Preparation and actor acknowledgement are separate stored changes. Consuming acknowledged recovery clears the pending pointer without deleting preserved bytes. Explicit authenticated discard clears only the named capture's bytes and compare-clears its pointer, retaining any newer pending capture.

The composed provider checks current authority before opening/resolving bindings, authorizing operations or subscribing to actor updates. Its close method closes the admission; authority close notifications also reach the registry when called directly. A genuinely closed admission invalidates all its leases/subscribers, including when discovered on an edit operation. A denied field read releases only that field's leases/subscribers and preserves authorized sibling fields. Removed subscriptions receive a final empty roster. A stale handle cannot disturb a rotated session. These methods are host preparation seams; the DS editor-graph binding source remains H3.

`SessionRegistry` owns one document resource per tenant/workspace/document. Each local mount has an independent lease; fields use `field:<key>` and `fieldmeta:<key>`, including a legitimate field named `meta`. Only host schema facts use root `meta`. Empty, duplicate and colon-containing descriptor keys refuse before the resource factory. Binding resolution checks document, session and field together and requires an active lease for the actor/admission. Last release closes transport and retains document state. Explicit host close invalidates the current session's leases/listeners. A drained resource refreshes its cached envelope from newly admitted authoritative facts; it never migrates the text or writes root schema facts again. Epoch regressions and retired session IDs refuse. Actor updates deliver both actor identity and awareness client ID and remove departing/revoked participants.

The UI adapter delegates all L0 methods to existing `object-lock.ts`. Renewal re-reads the lock and calls acquire only for its current holder; non-holders return the authoritative snapshot. H1 supports object-level locks only and refuses defined `unitRef` claims; H9 owns element-level claims. It consumes existing streamHub `lock_update`/`presence_update` events and re-reads snapshots rather than trusting event payloads. Every ping also re-reads, covering recovery on the first recovered ping without another SSE connection. Subscriptions cancel pending delivery and detach on release. Controlled fields use L0 gating; live fields use edit authority and admission together. `scopeRef` is a trusted host mapping label. Malformed server timestamps surface through `onError`, retaining the last snapshot rather than synthesizing an unlock.
