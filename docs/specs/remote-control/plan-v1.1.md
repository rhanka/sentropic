I4 pins separate keyrings/rotation/revocation/fixtures.

Only input and permission-response may act. Input preserves exact decoded UTF-8 bytes/newline, <=32 KiB, rejects C0 except HT/LF/CR, DEL/C1 and ESC; no shell/exec/spawn/argv/environment path exists. Qualified native provider prompt-input hook submits literal data atomically under input-ready/request fencing; PTY-only providers are unavailable. Input while any permission is pending refuses permission_pending, including y/newline and same-buffer approval-like text. Exit/suspend closes control, and CLI runs directly without a wrapper interactive shell. Only a complete source-issued permission card bound to current request ID/generation/context may submit Allow/Deny via the shared request CAS. Unknown/unqualified provider or incomplete state refuses. RC0 §3.3.2 is normative.

Control requires actor issuer/sub == approved registration owner, active exact-workspace membership, allowed nonviewer role and operation scope, current control consent and enabled owner-wide switch/epoch. Membership/admin/read share never delegates control. A checks at enqueue/claim; B verifies signed predicate and local owner/session/scope/request fences. Refusal vocabulary is RC0 §3.3/§3.4.1. Another member, administrator and read-only share are mandatory negative vectors; future delegated control is out of v1.

A transaction failure gives zero handoffs. B must verify outer registration and D2 proof, reserve the actual permission request under the common native fence and fsync consumed actionId+digest before effect. A/B controller, revocation and epoch fences prevent local/remote double resolution. At-most-once dispatch is required; crash between consume/effect/result may remain outcome_unknown. An absent record after handoff is never proof of zero effects.

TTL is <=30 seconds, also bounded by original session proof/attestation, nonce, source/consent lease <=60 seconds, controller and registration expiry. Clock error <=5000 ms is subtracted; invalid clocks refuse. Recheck at enqueue, claim and native consumption/effect. Renewal/reconnect never extends an existing deadline. Observed denial takes effect at the fence; otherwise permits cannot outlive their original bounded deadline. Report qualified revocation windows.

Revoke/exclusion/logout/membership or scope loss/global control-off raise the authority epoch, CAS-cancel queued actions, deny new claims and append audit/outbox in the same locked transaction. V1 adds no action-stream revocation signal; existing source denial plus immutable expiry bounds post-claim admission to <=35 seconds, conservatively including skew. This bounds a new effect's admission, not rollback of a tool already started. A purges payload/nonce/proof bytes at handoff/expiry/cancel; only digests/fences remain. Use per-action erased encryption keys and non-backed-up TTL payload storage so metadata backups cannot retain secret input. Unknown outcomes remain visible; automatic resend is prohibited, but the owner may explicitly submit a new actionId with a warning that the previous effect is uncertain.

RC0 §§3.5–3.6 define joint rate/size/concurrency bounds, bounded outbox/query recovery and append-only RemoteActionAudit. A atomically records actor/action/target/payload digest/decision/times/result/native receipt, with hash chaining and independent signed checkpoints every 15 minutes. A and B retain metadata >=90 days and >=dedup/restore horizon, preserving external replay fences. B journals consumption/request-CAS/effect/result and exposes a local remote-control indicator/off control. RC4 displays owner history without payload. Audit failure blocks new A admission/claim; local denial remains available. Tamper detection, purge and restore are explicit witnesses.

No offline executable queue. Disconnect fences queued commands/connection generation; handed-off work is query-only. Limits: 64 KiB complete action and SSE frame/buffer; 32 KiB decoded input; 16 KiB result; one pending/native session, four/owner-source and sixteen/host charged against inherited pending budgets. Lower provider limits win. Keep separate usable denial/revoke/result capacity, bounded outboxes and no saturation bypass across bindings. Dedup/consumption fences survive all validity/restore horizons.

Keep default-off capture, consent before read/subscription/hash/serialization, revision/future-child/history selectors, no outage backfill, independently authorized offline retained reads, immutable per-channel first-admission deadlines/default no expiry, writer-settled purge and external epoch restore fencing.
