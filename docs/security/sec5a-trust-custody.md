# Fresh Sigstore custody qualification

The acquisition no longer reads any operator-specific evidence directory or existing Sigstore home. `make security-qualify-signature ENV=test-sec5a-trust`, under the shared Docker flock, downloads the frozen Trivy index, platform manifest, config and attestation bundle from public Docker Hub, plus Cosign 3.1.4 from its immutable GitHub release. Every downloaded executable or OCI object is hash-checked before use. The Node execution image remains pinned by digest.

Cosign initializes fresh Sigstore TUF metadata in a newly created empty home. Its embedded release root is the bootstrap trust anchor; root rotation, role signatures, target hashes and expiration are enforced by the native client. The approved slim Node image lacks system CA certificates, so a disconnected Node process exports its embedded Mozilla TLS roots for the container's TUF acquisition. Host curl uses the host's TLS CA store, then every fetched artifact is hash-checked. TLS server authentication and TUF artifact authentication remain separate. The networked verifier mounts only its binary, TLS roots and new TUF home; no operator CA bundle, prior roots, registry credential or daemon socket enters it.

The newly authenticated `trusted_root.json` and frozen attestation then verify the exact Trivy index with networking disabled and exact upstream issuer/identity. Three cryptographic controls refuse a changed index, a well-formed root bundle containing an unrelated valid Mozilla CA, and a well-formed attestation with one signature byte changed. Expected native error classes are mandatory; Docker or parsing failures cannot count as successful controls. The [public receipt](sec5a-trust-custody.json) retains native exit codes, log/artifact hashes and the raw signed TUF/root bytes in base64, allowing their hashes to be independently recomputed. The generator checks artifact pins, bundle linkage, timestamp/snapshot/targets version linkage, target hashes and expiration. `make security-qualify-trust-receipts ENV=test-sec5a-trust` deterministically publishes the fixed allowlisted file from the retained inputs and verification timestamp. Full raw logs remain in `tmp/security-qualify/` and contain no credentials.

The generator checks expiration at the retained native verification timestamp so archived public bytes remain reproducible. Native TUF initialization enforces real-time expiration during each new acquisition. Archived publication grants no runtime freshness or admission. Trial stdout is separate from each input; the changed index must be exactly the frozen index plus one newline, and the changed signature must preserve DER structure with only its final scalar byte altered.
