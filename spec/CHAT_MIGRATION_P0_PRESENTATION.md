## Dated chat-local deviation budget

On **2026-10-28**, freeze the enumerated source/selector routes and 75 widget `dark:` tokens as the starting budget. P1/P2 may not introduce a new chat-local override or increase the widget count; P2b/P3 reduce it to zero jointly. Count `dark:` occurrences, not matching lines; compare the complete override selector list and dynamic style destinations as well. DS theme vocabulary changes are owned by DS and require matched light/dark/density/focus/status/disabled/portal evidence.

P3's gate tests user light while OS dark, user dark while OS light, auto/system transitions, small density and alternative presets, portal scope, keyboard focus and reduced motion **after** removing the package source directive. The published Entropic CSS alone supplies no dark branch; the chosen DS mechanism must be demonstrated. No transverse `ui/src/**` freeze is imposed; owner-held D7-a remains separate. P0 records these obligations and makes no CSS change.
