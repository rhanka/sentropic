# P0 — Behavior, owner and qualification matrix

Baseline and ownership vocabulary: [contract](CHAT_MIGRATION_P0.md). This is the migration acceptance oracle, not a claim that the incomplete turnkey path already passes. Every source path is additionally assigned in the source map. Tests named without a prefix are under `packages/chat-ui/tests/`; existing tests are evidence anchors to evolve in the named lot, not proof of untested app parity.

Role keys: **UI** = chat visual maintainer (DS after M2); **RT** = Sentropic runtime maintainer; **APP** = web integration lead; **EXT** = Chrome/VSCode maintainer; **DATA** = Sentropic API/data maintainer; **DS** = DS primitives/theming maintainer. Each row names the accountable role for the behavior and its supporting boundary.
