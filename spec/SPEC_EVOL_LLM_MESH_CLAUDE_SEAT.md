## 1. Current state and gaps

In this library a seat is an `AccountTransportAccount`, not a new `ProviderId` or an API key. Keep `targetProviderId: 'anthropic'`, `transportProviderId: 'claude-code'`, owner-scoped account identity, and `metadata.billing_type: 'seat'` following native Muse (`packages/llm-mesh/src/account-transports.ts:20`; `packages/llm-mesh/src/service/local-account-transport-service.ts:381`). A seat label alone does not establish custody or provider entitlement.

- **A2 — verified (source):** [Official public Claude Code 2.1.80 npm manifest](https://registry.npmjs.org/@anthropic-ai/claude-code/2.1.80) and [package archive](https://registry.npmjs.org/@anthropic-ai/claude-code/-/claude-code-2.1.80.tgz), inspected `package/cli.js` as text, never executed.
