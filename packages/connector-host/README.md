# @sentropic/connector-host

Pure provider-agnostic mount for @sentropic/mcp-platform connector adapters with injected deny-by-default host ports.

Install with `npm install @sentropic/connector-host` and import from `@sentropic/connector-host`.

## Releases

First publication uses the owner-operated [web bootstrap](../../scripts/publish/README.md); later releases use CI trusted publishing.
