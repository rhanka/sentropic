# Cowork F3 MVP adversarial re-run 2

Cycle 2 does not clear the contained-kiosk alpha. The final signed start claim closes the narrow post-ack race only when server revocation wins before `acknowledged -> executing`; it does not make an executing native action abortable or Stop-revocable. The runtime surface guard also admits any executable named `notepad.exe` and does not constrain click coordinates to the measured HWND. One previously closed isolation property regressed, and three fresh critical/high defects remain.
